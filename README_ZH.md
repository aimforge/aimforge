## 这是什么

不是什么简单无意义的训练系统。是一套把瞄准当「可测量科学」来做的完整专业训练体系：

- 你打出的**每一发子弹**都被单独记录——偏移矢量、过冲方向、修正链、反应时间分布
- 垂直大模型 **AimTop**（射击数据后训练）读你的每一块数据，直接写出下一步训练处方，为你自动调整训练参数
- AI 不止出报告——它会**给你这个人建模**，让你的训练越来越科学，训练方向越来越准确
- 训练 → 诊断 → 复盘 的完整闭环，覆盖 Web 端与移动端

## 你会被量化成什么样

| | |
|:---:|---|
| **每一发** | 偏移量、过冲方向、修正了几次才中——单发记录，不是一锅总分 |
| **完整分布** | 你的反应时间是整条分布，不是一个平均值 |
| **8 项能力** | 定位、反应、跟枪、决策……逐项 0-100 分，弱在哪一层，一屏看清 |
| **毫秒级** | 跟枪"贴上去"要多久、手抖了多少——全部可测 |
| **数百项指标** | 上传一份对局 Demo，逐帧告诉你每一波对枪输在哪 |
| **周对周** | 能力趋势追踪——这周比上周，涨了哪项，掉哪项 |

## 核心技术

**分数底下是真数学。** 你在这的每一个分数都不是拍脑袋——底下是高等数学，而且每一条都能翻译成人话：

- **跟枪慢？** 拟合一条指数曲线，量出你"贴上去"要几毫秒。慢在哪一环，说得清。
- **快但飘？** 用信息论算你的速度和精度绑没绑死。绑着，说明你还没练开。
- **说手感飘？** 把轨迹求三次导，抖了几个单位，数字说话，不用猜。
- **调灵敏度？** 按对数定律建模你的体感——因为你的人体，天生就是台对数机器。

**AI 智能热身系统。** 热身是算出来的，不是模板：多维状态问卷，多种热身形态按当日状态重新生成；系统内的 AI 持有建模工具——它给你写公式、带置信度存入档案、参与后续每一次计算，完全透明。

**AimTop。** 垂直领域大模型，使用海量射击遥测数据与射击运动学知识后训练。诊断更准，注意力更集中。真模型，不糊弄。

**3D 弹道引擎。** 还原游戏手感，为你的训练迁移做好直接保障。

**数据主权。** 脱敏加密传输，仅数值型指标。不进任何模型训练集，不卖、不换、不送。
